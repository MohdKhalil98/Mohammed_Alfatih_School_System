# تفعيل وحدة الانضباط الطلابي

## 1) تطبيق الهجرات (Supabase ← SQL Editor، بالترتيب)
1. `supabase/migrations/20261014000001_discipline_auth_roles.sql`
2. `supabase/migrations/20261014000002_discipline_schema.sql`
3. `supabase/migrations/20261014000003_seed_violations_pending.sql`

الهجرات إضافية فقط (أعمدة اختيارية على classes/students وجداول جديدة) ولا تمس بيانات الحضور.
خذ نسخة من صفحة «حفظ البيانات» قبل التطبيق.

## 2) أول مدير نظام
1. Supabase ← Authentication ← Users ← Add user (بريد + كلمة مرور، مع Auto Confirm).
2. SQL Editor:
```sql
insert into profiles (user_id, full_name, role)
select id, 'اسم المدير', 'admin' from auth.users where email = 'EMAIL';
```
3. بعدها يضيف المدير بقية المستخدمين من «إعدادات الانضباط والصلاحيات» (بعد إنشائهم في Authentication).
4. يُنصح بتعطيل التسجيل الذاتي: Authentication ← Providers ← Email ← إيقاف Allow new users to sign up.

## 3) استكمال قاعدة المخالفات من نص اللائحة
المخالفات المزروعة (49) بحالة «بانتظار المراجعة»، مصدرها ملخص صفحة الوزارة بصياغة غير حرفية. من «قاعدة المخالفات الرسمية»
أدخل رقم البند والنص المرجعي والمعالجات من نص القرار 279/2025، ثم اعتمد كل مخالفة. ملف PDF الرسمي لا يمكن استخراج نصه آليًا
(خطوط بلا ترميز نصي)، لذا يلزم لصق نص المواد 5–8.

## 4) المدد النظامية
الإعدادات تحمل قيمًا من الملخص: التوصية 2، الإخطار 3، التظلم 7 (أيام عمل). طابقها مع النص ثم فعّل «طابقتُ المدد».

## 5) النشر
الواجهة تحتاج `VITE_SUPABASE_URL` و`VITE_SUPABASE_ANON_KEY` عند البناء (`npm run build`). أضف عنوان موقعك في Authentication ← URL Configuration.

## حدود معروفة
- أقسام الحضور والغياب الحالية ما زالت مفتوحة بمفتاح anon كما كانت؛ الحماية الجديدة تشمل جداول الانضباط فقط.
  تعديل بيانات الطالب الإضافية (رقم مدرسي/ولي أمر) يمر عبر جدول students المفتوح.
- «PDF» عبر نافذة طباعة المتصفح (حفظ بصيغة PDF)، لا توجد مكتبة PDF.
- لا يوجد إرسال واتساب/إشعارات؛ رسالة للنسخ وتسجيل يدوي للتاريخ.
- حالة «تأخر» غير مسجلة في وحدة الحضور الحالية.
- الاستعادة الآلية في «حفظ البيانات» تُمنع عند وجود وقائع انضباط.
